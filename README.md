# 个人作品集网站 · 使用说明

一个零依赖的纯静态站点。首页 + 五个板块（自我介绍 / 账号运营 / 数据分析 / 图片作品 / 剪辑作品）+ 最终页。
风格：近黑底色 + 橙色单强调色，滚动叙事 + 数据可视化 + 作品灯箱。

---

## 一、先改这里：所有文案和数据都在一个文件里

打开 `assets/js/content.js`，从上到下改一遍即可，改完刷新页面就能看到。
带 `👉` 注释的地方是需要换成你自己信息的位置，最重要的是这几个：

| 位置 | 变量 | 说明 |
| --- | --- | --- |
| 姓名 | `profile.name` / `profile.latin` | 首屏大字和页脚大字 |
| 岗位 | `profile.role` / `profile.target` | 首屏小标题、顶栏、期望岗位 |
| 联系方式 | `profile.email` / `wechat` / `phone` | 最终页与页脚 |
| 社交主页 | `profile.socials[].href` | 留空则不显示，填了就变成可点击链接 |
| 首屏标语 | `profile.headline` | `<em>…</em>` 里的字会显示为橙色 |

各板块的内容分别在 `about`、`accounts`、`data`、`works`、`video`、`contact` 里。
凡是字符串里出现 `<em>…</em>` 的地方，都是"这句要被高亮成橙色"的意思，可以照抄结构。

## 二、加图片和视频（两种方式，任选一种）

现在页面上的作品图都是**程序生成的占位图**（纯 SVG，不需要联网），
占位图上会直接写着"该放哪个文件名"（例如 `assets/img/01.jpg`）。放入真实素材后占位图自动消失。

### 方式 A：按序号命名（不用改任何代码，推荐）

编号对应页面上每张作品**左上角的数字**：

| 文件 | 对应位置 |
| --- | --- |
| `assets/img/01.jpg` … `09.jpg` | 「图片作品」第 01 … 09 张 |
| `assets/img/me.jpg` | 「自我介绍」里的个人照片 |
| `assets/video/01.mp4` … `06.mp4` | 「剪辑作品」第 01 … 06 条视频 |
| `assets/video/01.jpg` … `06.jpg` | 对应视频的封面图（可不放） |

放进去、刷新页面就会显示。图片自动识别 `.jpg` 和 `.png`，视频自动识别 `.mp4 / .mov / .webm`；
其他格式（`.jpeg / .webp` 等）用方式 B 填 `src` 一样能显示。

### 方式 B：用自己的文件名

把文件放进 `assets/img/`（视频放 `assets/video/`），然后在 `content.js` 里给对应条目填 `src`：

```js
{ title: "成分科普封面系列", category: "封面设计", ratio: "tall",
  src: "assets/img/我的封面.png", desc: "……" }
```

视频还支持外链，不用下载到本地：

```js
{ title: "探店 Vlog｜杭州 5 家宝藏咖啡", platform: "抖音", duration: "02:14",
  views: "128w", rate: "41%", role: "脚本 + 剪辑",
  src: "", embed: "https://player.bilibili.com/player.html?bvid=BVxxxxxxx" }
```

- 填了 `src` 就以它为最高优先级，找不到才会去按方式 A 的序号找，最后才显示占位图。
- `ratio` 写素材本身的比例，例如 `"9:16"`、`"3:4"`、`"16:9"`、`"1:1"`、`"2:1"`。
  缩略图会严格按这个比例显示，所以图片/封面永远是**完整的一张**，不会被裁掉。
  填错或留空也没关系：图片加载完成后，脚本会自动按真实尺寸校正。
- `category` 决定它归到哪个筛选标签里，想加新分类就在 `works.filters` 里补一个名字。
  （筛选标签现在会自动对齐作品里真实出现的分类，不会再出现点了没内容的空标签。）

### 两个板块的排版规则

- **图片作品**：3 列瀑布流（窄屏 2 列），每张图按自己的比例完整显示、互不裁切，比例不同也不会留空洞；
  点开是灯箱大图，左右方向键翻页、Esc 关闭。
- **剪辑作品**：3 个一行、共 3 行（窄屏 2 列、手机 1 列），顺序就是 `content.js` 里的 01→09；
  封面按自身比例完整显示。横版封面（16:9 等）的卡片框最矮不低于 4:5，封面居中、上下留黑边，
  这样整行不会出现大片空白 —— 想让它严格按 16:9 变矮也可以，改 `main.js` 里的
  `VIDEO_FRAME_MAX_AR`（数值改成 1 即不限制）。

### 各板块的图片位置一览

| 板块 | 文件名 | 说明 |
| --- | --- | --- |
| 自我介绍 | `assets/img/me.jpg` | 个人照片 |
| 账号运营（展开后左侧） | `assets/img/account-01.jpg` … `account-05.jpg` | 每个账号 1 张截图，编号对应第几个账号 |
| 数据分析 · 漏斗右侧 | `assets/img/data-hot.jpg` | 爆款笔记截图 |
| 数据分析 · 看板组 | `assets/img/data-daily.jpg`、`data-weekly.jpg`、`data-competitor.jpg` | 日常监控 / 周度分析 / 竞品分析 |
| 图片作品 | `assets/img/01.jpg` … `09.jpg` | 作品图 |
| 剪辑作品 | `assets/video/01.jpg` … `09.jpg` | 视频封面 |
| 剪辑作品 | `assets/video/01.mp4` … `09.mp4` | 视频文件 |

### 数据分析板块的四个区块

1. **链路增长闭环模型** —— 7 步横向流程卡片（图标 + 标题 + 一句话解释），底部一句总结。
2. **内容素材筛选 & 复盘决策漏斗** —— 左侧 6 级漏斗（逐级收窄），右侧一张爆款笔记截图。
3. **核心监测指标体系** —— 内容指标 / 投放指标 / 转化指标三类。
4. **复盘方法论** —— 单独颜色模块，固定复盘三板框架；下面是三块数据看板截图位。

文字全部在 `content.js` 的 `data` 里，可以直接改；想调整漏斗级数、流程步数，
增加或删除数组里的条目即可，版式会自动适配。

`assets/img/` 和 `assets/video/` 两个文件夹里各有一份 `把图片/视频放这里.txt`，
里面写了同样的说明和尺寸建议，放在手边方便对照。

### 素材大小必须控制（会影响能不能上线）

| 素材 | 建议 | 超限后果 |
| --- | --- | --- |
| 个人照片 | 宽 1000–1600px，< 500KB | 太大手机打开很慢 |
| 作品图 | 宽 1200–2000px，单张 < 500KB | 9 张图加起来超过 3–4MB 就会明显卡 |
| 视频 | **单个 < 30MB**（58 秒的片子压缩到 1080p 约 10–20MB） | GitHub 单文件上限 100MB、Vercel 也是 100MB，超了直接传不上去 |

照片和图片用系统「画图」另存为 JPG、或 [squoosh.app](https://squoosh.app) 拖进去压一下就行；
视频用剪映导出时把分辨率设为 1080p（或 720p）、码率 6–10 Mbps。
视频也可以直接传到 B站，然后用 `embed` 字段嵌入播放地址，本地就不需要放视频文件。

> `assets/img/me.jpg` 是帮你从 19MB 的原图自动压到 326KB 的版本（1200×1600），
> 页面会自动优先使用它；确认显示没问题后，原来的 `me.png`（19MB）可以删掉。

## 三、本地预览

直接双击 `index.html` 就能在浏览器里打开，不需要安装任何东西、不需要构建。

服务端预览（可选，某些浏览器对本地文件限制更严时用）：

```bash
npx serve .
# 或
python -m http.server 8000
```

## 四、部署上线（都在 5 分钟内）

**Vercel（推荐，最快）**

1. 把整个文件夹推到 GitHub 仓库；
2. 打开 vercel.com → New Project → 选中该仓库 → 直接 Deploy（框架选 Other，Build Command 留空）；
3. 得到 `xxx.vercel.app` 域名，可在设置里绑定自己的域名。

**GitHub Pages**

1. 推到 GitHub 仓库；
2. Settings → Pages → Source 选 `Deploy from a branch`，分支选 `main`、目录选 `/ (root)` → Save；
3. 等一两分钟，访问 `https://用户名.github.io/仓库名/`。

**Netlify**：把整个文件夹直接拖进 app.netlify.com 的 Deploy 区域即可。

## 五、字体与配色

- 字体：页面通过 Google Fonts 加载 Archivo（西文）+ Noto Sans SC（中文）+ JetBrains Mono（数字/标签）。
  页面里同时写了系统字体兜底，所以即使字体加载失败（比如在国内网络下），排版也不会崩。
- 如果想让字体在国内也秒开，可以把字体的 `.woff2` 文件下载到 `assets/fonts/`，在
  `assets/css/style.css` 顶部用 `@font-face` 定义，并把 `index.html` 里那一行 Google Fonts `<link>` 删掉。
- 配色集中在 `assets/css/style.css` 最上面的 `:root` 里，改 `--orange` 就能整站换色
  （默认 `#FF5A00`），改 `--bg` 换底色。

## 六、文件结构

```
.
├─ index.html              页面结构（静态骨架 + 所有弹层）
├─ assets/
│  ├─ css/style.css        全部样式（配色变量在最上面）
│  ├─ js/content.js        ★ 你的全部文案与数据，改这个文件
│  └─ js/main.js           交互：预加载、滚动叙事、图表、灯箱、筛选、光标
├─ preview/                各板块的渲染效果预览图（可删，也能作为截图素材）
├─ tools/check.mjs         开发自检脚本：无头浏览器打开页面、检查报错并截图（可删）
└─ README.md
```

自检脚本用法（改完内容想确认没改坏时）：

```bash
# 1) 先启动一个带调试端口的无头浏览器（Windows 上 Edge 路径如下）
"C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe" --headless=new --remote-debugging-port=9226 --user-data-dir=%TEMP%\edge-check about:blank

# 2) 再运行自检
node tools/check.mjs 9226
```

它会在 `.check/` 里生成截图，并打印出页面是否有 JS 报错、素材有没有被识别到。

## 七、交互说明（给访客的体验）

- 首屏：名字预加载动画 → 大字标题 → 底部板块快捷导航。
- 账号运营：每行可点击展开，分别是"关键动作 / 结果 / 复盘"。
- 数据分析：滚动到视口时，折线图描边生长、数字滚动、环图上色；折线支持鼠标悬停看每月数值。
- 图片作品：点分类筛选，点图片放大查看，支持左右方向键与 Esc。
- 剪辑作品：点卡片弹出播放层（支持本地 mp4 或 B站/YouTube 嵌入）。
- 每一屏右上/右下都有滚动进度与当前板块提示；手机上会自动收起侧边装饰并简化导航。
